# 明朝体风格标题字体

本地字体：`unit02-mincho-black.woff2`，应用内名 **Unit02 Mincho**。

原字体为开源 **Noto Serif CJK SC Black**，来源：
https://github.com/notofonts/noto-cjk/tree/main/Serif

原文件：
https://raw.githubusercontent.com/notofonts/noto-cjk/main/Serif/OTF/SimplifiedChinese/NotoSerifCJKsc-Black.otf

许可证为 SIL Open Font License 1.1，全文随附 `OFL-NotoSerifCJK.txt`。该子集由原模板提取界面标题所需字形并重命名；本候选包分发已有子集，保留原版权与许可证元数据。原始下载仅在制作目录 `.verification`，不安装系统字体。

该字体用来表达明朝体粗细反差与 EVA 标题气质，不声称是动画使用的商业原版字体。正文、输入框、模型选项与代码继续使用易读的系统字体。
